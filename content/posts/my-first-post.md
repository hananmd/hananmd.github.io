## Featured Projects

### 🏰 Maze of UCSC
A 3D maze runner game built entirely in **C**, set across three floors of a block-based environment. The game features walls, stairs, poles, and special *Bawana effect* cells that mess with the player.

What made this project meaningful wasn't just the game mechanics — it was the architecture. I structured it as modular files (`main.c`, `game.c`, `game.h`) and implemented the geometry and traversal logic from scratch. It's the kind of project that teaches you what systems programming really feels like under pressure.

> *This one's close to my heart — it lives on a university server and still surprises me sometimes.*
